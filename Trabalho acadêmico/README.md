# Trabalho acadêmico — Interface e Jornada do Usuário

Este diretório contém o trabalho acadêmico do projeto "Interface e Jornada do Usuário". O objetivo deste trabalho é documentar e apresentar as pesquisas, protótipos e entregáveis relacionados ao estudo da experiência do usuário (UX) e do design de interface (UI).

## Conteúdo
- `docs/` — materiais de pesquisa, referências e anotações (se aplicável).
- `figma/` — links ou arquivos exportados do protótipo (se aplicável).
- `wireframes/` — imagens ou PDFs dos wireframes.
- `prototipo/` — versão estática do protótipo (HTML/CSS/JS) ou instruções de acesso.
- `relatorio.pdf` — relatório final do trabalho (se incluído).

> Ajuste os nomes das pastas acima conforme os arquivos que você adicionar ao diretório.

## Objetivo
Descrever a jornada do usuário, justificar decisões de design e apresentar as soluções propostas para melhorar a usabilidade e a experiência do produto analisado.

## Como visualizar
- Se houver um protótipo estático, abra o arquivo `index.html` no navegador.
- Para arquivos de design (Figma, Sketch), inclua o link ou o arquivo exportado neste diretório.
